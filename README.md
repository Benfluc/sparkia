# SparkIA

Site institucional da **SparkIA**, desenvolvido para apresentar a empresa, seus serviços, soluções e informações de contato.

## 🚀 Sobre o projeto

O SparkIA é um site institucional desenvolvido com tecnologias web tradicionais, com foco em:

* Design responsivo
* Navegação simples e intuitiva
* Apresentação dos serviços
* Identidade visual da empresa
* Compatibilidade com dispositivos desktop e mobile

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Google Fonts
* SVG / PNG para elementos gráficos
